# Motion Sensor Device – Electronics Project

## About the Project
This project is based on a **Motion Sensor Device**, designed to detect movement using a sensor.
It is commonly used in security systems, automatic lighting, and smart devices.

## Working Principle
The motion sensor detects changes in infrared radiation or movement in its surroundings.
When motion is detected, the sensor sends a signal which activates the output device
such as an LED, buzzer, or alarm.

## Components Used
- Motion Sensor (PIR Sensor)
- IC 
- LED
- Resistors
- Power Supply
